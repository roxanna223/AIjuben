### 1.1 产品定位

「歧路」是一款 AI 互动叙事游戏(MVP 阶段):玩家在多分支悬疑剧本中做选择,由 LLM(DeepSeek)实时生成叙事与反馈,最终走向不同结局。

- 剧本1:《午夜列车》(悬疑/无限流,6 章,5 结局)
- 剧本2:《规则楼》(无限流/规则怪谈,3+ 结局)
- 模式:Mock(脚本驱动,可离线测试)/ LLM(生产,DeepSeek deepseek-chat)
- 呈现形态(v0.3.0 起):**文字游戏式人物对话**——每句台词带说话人,前端渲染为带名字/头像的对话气泡(主角右侧、NPC左侧、旁白居中);六个角色均有程序手绘 SVG 头像,后续可无缝替换为 AI 生成人物图
- 玩法(v0.4.0 起):**逐句播放**——每次只显示一句话,点击对话区或按空格推进;顶栏「▶ 自动播放」按行放慢推进、到选项处自动暂停,选择后自动继续;交互点每 5~6 句对白一次(旁白不计),输入区仅在交互点出现(v0.4.1),选择影响以「✦ 影响」提示即时可见(v0.4.2)
- 确定性(v0.4.4 起):**fixed_plot 固定剧情锚点**——用户不可操作的基础剧情细节在剧本中定稿并写明依据(如"第一站消失的是沈阿婆,依据:名册红圈"),跨局一致、省 token;只有玩家行为改变了依据才产生变数
- 故事导图(v0.4.5 起):**渐进解锁的路线思维导图**——顶栏「🗺 故事导图」查看;只有玩家到达过的节点才点亮(主线节拍/玩家自由输入自创的剧情节点/结局),每次选择画一条带选项文案的分叉边,未走上的节拍以空心"岔路"占位呈现(不透露剧情内容),随会话存档持久化

### 1.2 技术架构

```
浏览器(static 前端) → nginx(80,反代+安全头) → uvicorn/FastAPI(127.0.0.1:8000)
                                                      ├─ engine/(宪法/状态/导演/账本/流水线/导图/校验量表)
                                                      ├─ provider: Mock | OpenAICompat(DeepSeek云端)
                                                      ├─ data/sessions/*.json   会话存档
                                                      ├─ data/usage.jsonl       LLM用量埋点
                                                      └─ data/events.jsonl      玩家行为事件(v0.2.0新增)
```

- 技术栈:Python 3.11 / FastAPI / uvicorn / pydantic;前端原生 HTML+JS
- 推理不落地:所有 LLM 调用走 DeepSeek 云端 API,服务器只是转发+状态存储

### 1.4 数据资产(三类,均在 `data/`)

| 数据 | 文件 | 内容 | 用途 |
|---|---|---|---|
| 会话存档 | `sessions/s_*.json` | 玩家状态全量(数值/记忆/事件账本/结局) | 游戏续玩、体验指标 |
| 用量埋点 | `usage.jsonl` | 每次 LLM 调用 tokens/延迟/剧本 | 成本核算、质量监控 |
| 行为事件 | `events.jsonl` | 每请求事件:页面访问/开局/回合/复盘等,IP 加盐哈希脱敏 | 玩家行为分析(v0.2.0 新增) |

### 1.5 安全措施(v0.2.0 就位)

1. **API Key 零泄露面**:密钥只存服务器 `.env`(600 权限,仅 root),前端/接口/日志均无密钥;全项目 `grep sk-` 仅命中 `.env`;
2. **管理接口鉴权**:`/api/admin/metrics`、`/api/admin/events` 需 `X-Admin-Token` 请求头(令牌存 `deploy/env.server`,不入 git);
3. **IP 限流**:普通 API 60 次/分/IP,回合接口 20 次/分/IP,超限返回 429(防刷量=防盗烧 API 配额);
4. **行为数据脱敏**:IP 加盐 SHA-256 截断,不存原始 IP;User-Agent 截断 120 字符;
5. **nginx 安全头**:`X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy`;
6. 请求体上限 2M、LLM 超时 90~120s、异常降级 Mock。

- 三种运行环境落地:
  - 构建期:`scripts/validate_content.py --mock` 全量校验 mock 脚本(两个剧本零 error);
  - 运行期:审查器 Critic 委托量表做变化类校验;`validation_report`/`validation_warn` 每场落事件账本;一致性审查扩展 `magnitude_issues`(幅度过当→警告不驳回);
  - 审计期:`scripts/validate_content.py --sessions` 离线扫描历史会话——实测揪出 midnight-train 190 个会话 316 条、rule-tower 79 个会话 160 条历史违规(正是"消失提前触发/b3保留事实提前授予"类);
- 剧本口径配置:两个剧本新增 `validation` 段(理智值/信任的剧情点白名单+幅度上限+b1/b3 理由禁用"消失"类词;名册/怀表/结局类事实的节拍与来源声明),宪法校验该段引用合法性;
- 涉及文件:`engine/validation.py`(新增)、`engine/constitution.py`、`engine/pipeline.py`、`stories/{midnight-train,rule-tower}.json`、`scripts/validate_content.py`(新增)、`tests/test_validation.py`(新增 15 项)、`docs/02-剧本Schema规范.md`、`docs/03-系统架构.md`、`docs/07-工程化校验框架.md`(新增)、`README.md`、本文档;
