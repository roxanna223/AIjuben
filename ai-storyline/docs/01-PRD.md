# 「歧路」AI互动叙事平台 · 轻量PRD v0.1

> 状态：草案，待评审 ｜ 配套：02-剧本Schema规范 / 03-系统架构 / 04-样例剧本
> 调研基础：同目录上级 `点点穿书调研/` 两份报告（点点穿书全方位调研 + 竞品全景调研）

## 1. 产品定位

**一句话**：有剧本框架约束的对话体互动叙事平台——主线骨架由人定，实时剧情由AI写；用户的每一次选择都被记录为数值与性格倾向，AI"导演"据此为每个人规划出专属剧情路线。

**品类光谱上的位置**：

| | 点点穿书 | **本产品** | AI Dungeon |
|---|---|---|---|
| 分支内容 | 预先全写死 | 规则写死、内容实时生成 | 全即兴 |
| 自由度 | 固定选项 | AI选项 + 自由输入 | 无限 |
| 叙事质量 | 稳定但重复 | 有骨、有高潮、能收尾 | 易漂移烂尾 |
| 个性化 | 无 | 数值+倾向 → 千人千线 | 无结构 |

**调研依据**：点点穿书验证了"对话体+选项+数值"形态（华为4.9分/4400万下载），但选项是编辑按数据插入的工业参数；星野/Talkie验证了AI自由对话吃时长（日均70分钟），但纯自由叙事烂尾、DAU横盘；戏格/上头蛙/Storvia证明"框架约束+AI生成"是行业正在押注的中间形态——但均无"数值驱动的路线规划"。**这是我们的空白点**。

## 2. 目标用户与题材

- **MVP题材**：悬疑推理 / 无限流。理由：选择天然有意义（推理=信息取舍）、男女通吃、对话体生成质量可控、天然适配"路线分化"验证。
- **目标用户**：18-35岁，网文/互动小说/剧本杀/乙女用户。
- **核心场景**：通勤与睡前，单次 20-40 分钟"当一次主角"。

## 3. 核心循环（产品心脏）

```
读开场（AI按剧本宪法生成）
    ↓
剧情推进，出现选择点（AI生成2-4个选项 + 可自由输入兜底）
    ↓
用户选择 → 写入事件账本 + 更新数值 + 更新性格倾向向量
    ↓
导演规划器：决定下一个节拍、本场出场人物、解锁什么支线
    ↓
编剧生成下一段剧情（受当前数值/关系状态/倾向影响）
    ↓
……循环至节拍走完 → 检查结局条件 → 打出结局
    ↓
复盘：展示「你的专属路线图」+ 性格倾向画像（天然传播点）
```

关键体验承诺：**同一剧本，10个人玩出3条以上不同的路线**；但每一条都有骨、有高潮、能收尾。

## 4. MVP范围（Web）

1. 1个原创悬疑剧本《午夜列车》（约6章，见样例剧本）
2. Web对话界面：对话流 + 章节推进（纯文字，立绘为占位）
3. 选择：AI生成2-4选项 + 自由输入兜底
4. 数值：NPC好感/信任、理智值等全局数值 + 性格倾向向量（5维）
5. 路线：主线节拍硬约束 + 条件支线解锁 + ≥3个结局 + 结局后路线复盘图
6. 内容安全：剧本禁忌清单 + AI审查器（基础版）

## 5. 非目标（本期明确不做）

UGC剧本编辑器、AI生图/配音、付费系统、多端（小程序/App）、社交句评、多人剧本。

## 6. 成功指标

| 指标 | MVP目标 | 依据 |
|---|---|---|
| 单次会话时长 | ≥15分钟 | 点点穿书为碎片+沉浸混合场景 |
| 第1章完读率 | ≥60% | 点点穿书内部内容考核线 |
| 结局达成率 | ≥50% | 自定；针对纯AI烂尾病的验收线 |
| 路线分化度 | 10人 ≥3条不同结局路径 | 本产品核心卖点 |
| 次日留存 | ≥25% | 品类公开留存查不到，暂用粗基准，上线后校准 |
| 单局生成成本 | ≤0.5元 | 见架构文档成本模型（token是生命线） |

## 7. 关键风险与对策（来自调研的三盏红灯）

| 风险 | 对策 |
|---|---|
| 剧情漂移/烂尾/无高潮 | 主线节拍表硬约束 + 审查器兜底 |
| 内容安全（赛道最大系统性风险：橙光下架6年、筑梦岛被约谈、星野下架智能体） | 禁忌清单+审查器从架构第一天内置，后续接 moderation API |
| token成本失控 | 三层记忆摘要压缩 + 国产便宜模型 + 成本埋点 |
| "假自由"（选了没区别） | 选择必须真实影响节拍路径；复盘图暴露路径差异 |

## 8. 里程碑

- **Phase 0** 概念验证（1-2周）：单剧本跑通"选择→生成→结算"闭环
- **Phase 1** 可玩MVP（3-4周）：见第4节
- **Phase 2** 个性化增强：倾向画像、路线分享、复盘图打磨
- **Phase 3** 多剧本生产：Schema工具链、剧本上架流程
- **Phase 4** 商业化：订阅/买断（先验证再上；调研教训：选项付费墙已被差评反噬，不做）

## 9. 待定事项（评审时拍板）

1. 产品正式名（候选：歧路 / 百相 / 无界书 / 编剧局）
2. 自由输入是否进MVP首版（建议：进，作为选项之外的兜底）
3. 模型供应商（DeepSeek / 豆包 / Qwen，见架构文档选型建议）
4. 复盘图的"路线图"是简单时间线还是节点图（MVP建议时间线）
