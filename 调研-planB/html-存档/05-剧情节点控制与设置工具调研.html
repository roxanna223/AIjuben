01需求解析

本模块在已生成的剧情文本（调研4的章节正文）中找出供用户做选择的节点——往往涉及内心心理活动，并对选择点做分级管理与节奏编排。两个核心问题：(a) 大小选择的区分规则（大选择影响深远、后续配合图片或多媒体表现）；(b) 节奏与情绪控制（多少字/多长时间出现一个抉择点，张弛有度地拉扯用户心理）。

章节正文输入
→
候选点识别（心理活动/决策/关系时刻）
→
分级（微/小/中/大/关键）
→
节奏校验（对照情绪曲线）
→
选项与后果生成
→
多媒体标记（大选择）

四个核心技术问题

  • 选在哪：什么位置适合插入选择？"内心心理活动"如何被系统性识别，而不是随机截断？
  • 怎么分级：大选择与小选择的判定标准（后果范围/可逆性/可预测性），以及各级的视觉与多媒体差异。
  • 多密：选择点间隔的量化标准——不同平台/文体的实测数据给出什么区间？
  • 怎么拉扯：密集与放缓如何交替？情绪曲线如何指导"何时密集、何时留白"？

02大小选择的区分规则

综合商业互动叙事产品的做法，建议用五个维度判定级别：后果范围（波及谁）、可逆性（能否挽回）、可预测性（选项后果是否显而易见）、影响时长（当场/本章/全篇）、情绪权重（道德压力/情感浓度）。

级别典型场景后果范围可逆性间隔参考表现形态
微选择语气/措辞/小动作（如何回应寒暄）仅当下氛围完全可逆随时可加行内气泡，不打断阅读
小选择当下反应（追不追问/接不接话）本场景内可逆约500-800字两三个短选项，轻量反馈
中选择章节路径（去见谁/先办哪件事）本章+关系值半可逆约1-2章一次独立选择卡片，含简要后果提示
大选择主线分叉（站队/揭发/告白）全角色线+他人线不可逆每章至多1次全屏+CG+音乐+停顿，明确警示"影响深远"
关键选择世界级分歧（生死/救谁/遵守或破坏规则）开新世界线不可逆每线2-4次电影化演出+分歧预告+可回看分岔树

游戏业界参照

  • 《底特律：变人》：流程图（flowchart）事后可视化所有选择与未选路径——大选择的"分岔感"直接可见
  • Telltale系：限时选择（倒计时强迫直觉决策）+"XX会记住这个"的延迟后果提示
  • 《奇异人生》：小选择即时可回溯（倒带），大选择锁死——可逆性本身就是分级手段
  • 《质量效应》：模范/叛逆值的长期累积——微选择汇聚为大结局分支

"内心心理活动"节点的识别特征

  • 欲望冲突：文本出现"想要…但是…"式内心拉扯
  • 价值权衡：利己vs利他、规则vs情感、忠诚vs真相
  • 关系临界：说出/隐瞒、靠近/疏远的瞬间
  • 规则怪谈特有：遵守可疑规则vs相信直觉（认知撕裂点）
  • 悬念高点：开不开门、看不看信、追不追人

这些位置天然适合让用户"替角色做心理决定"——代入感最强。

分级的机器判定规则（伪代码）

  • scope ∈ {personal, relational, chapter, route, worldline} —— 后果范围的枚举
  • irreversible = true 且 scope ≥ route → 大选择（触发多媒体流程）
  • scope = worldline → 关键选择（联动调研4开新世界线）
  • predictability 由AI评估选项后果的明显程度：后果越难预测，越要配后果暗示（防"盲选挫败感"）
  • 级别在生成时声明而非事后猜测——选择节点是正文生成时同步产出的结构化数据，不是对成文的二次解析（更可靠）

03选择点频率与节奏数据

各平台实测/经验数据汇总，换算成"每多少字一个选择点"，为本项目给出可配置的默认区间。

平台/文体体量基准选择点节奏折算（字/选择）
Choice of Games（ChoiceScript）10-25万字/部；单次游玩约覆盖20%内容社群经验：250-500词一个选择约400-800字（英文词×1.6折中文）
Episode / Chapters（移动互动叙事）每章约2000字、15-20分钟每章6-10个选择（含付费点），间隔约200-300词约300-500字（高频商业化节奏）
日式视觉小说/ADV阅读速度约100-125词/分钟选择点间隔约10-20分钟；《428》按小时段分支约1500-3000字（低频沉浸节奏）
《80天》（Ink引擎）50-75万词、数千个选择约500-1000词一个事件节点约800-1600字
中文免费网文（番茄系）2000字/章；黄金三章：前300字钩子、500字冲突、1000字金手指500-800字一个爽点；2000字一小高潮；1万字一大反转情绪节点约500-800字
竖屏短剧1-2分钟/集、550-800字/集黄金3秒开场、30秒建冲突、5-15秒一个刺激点、末30秒钩下集约100-250字一个刺激点（极限密度）

本项目的建议默认值（可配置）

  • 基准节奏：约 600-900字 一个小/微选择（对齐网文爽点密度，保证"有事可做"）。
  • 章级结构：每章2000-3000字，含 2-4个小选择 + 0-1个中选择 + 至多1个大选择。
  • 大选择：每章至多1次，且优先放在章节后1/3（决策成熟）；关键选择每条角色线2-4次。
  • 放缓章节：每3-4章安排一个"叙事章"（纯阅读、无选择或仅微选择），让用户消化剧情——张弛交替（见P4）。
  • 换算阅读时长：中文阅读约300-500字/分钟，600-900字 ≈ 1.5-3分钟一次互动，与Episode体感一致。

拉扯用户心理的三种手法

  • 钩子循环：选择后立刻给小反馈（关系值/新信息），下一个钩子在反馈后出现——"选→果→钩"循环
  • 延迟后果：小选择的后果延迟2-3章显现（"XX会记住这个"），制造后怕与期待
  • 假安全感：连续轻松选择后突然给出限时大选择——密度落差本身就是张力

防过载原则

  • 选择疲劳：连续大选择会麻木——两个大选择之间至少间隔1个叙事章
  • 选项数量：微/小选择2-3项；大选择2-4项（选项越多越要配后果暗示）
  • 可跳过：微选择设"默认继续"倒计时，不强迫点击（不打断沉浸）

04情绪曲线与张弛控制

节奏数据的上层是情绪曲线：先有章节的情绪轨迹，再决定选择点放在哪、密还是疏。四个经典方法论 + 一个机器可读的打点方案。

Vonnegut「故事形状」曲线

纵轴=处境好坏，横轴=时间。经典形状：Man in Hole（掉坑爬出）、Cinderella（升-落-大涨）、Boy Meets Girl（相遇-失去-复得）、From Bad to Worse（一路下坠）等。用法：开线时选定角色主线的形状模板，作为章节情绪打点的参照基线。

Save the Cat 节拍表（Blake Snyder）

15节拍的结构位置：催化剂（约10%）、进入第二幕（约20%）、中点（50%，假胜利/假失败）、坏人逼近（50-75%）、一无所有（约75%）、进入第三幕（80%）、结局（80-99%）。用法：章节大纲生成时按节拍占比分配章节数，大选择对齐中点/一无所有/结局等强节拍。

起承转合（Kishōtenketsu）

四段式：起（引入）→承（展开）→转（转折，约占20-30%篇幅）→结（收束，10-20%）。与西方冲突驱动不同，靠"意外转折"发力，更贴合东方读者口味（也适合日常系/规则怪谈的反转节奏）。用法：单章内部结构的默认模板。

心流理论（Flow）的锯齿曲线

挑战-技能平衡：过难焦虑、过易无聊，理想难度曲线是波峰波谷交替的锯齿状而非单调递增。用法：选择的"心理难度"（道德压力/信息不全程度）随章节推进整体抬升，但必须有低谷章回血；微选择≈心流区的低挑战反馈。

章节情绪打点（机器可读方案）

每章大纲/正文生成时，同步输出逐场景的情绪打点：tension（紧张度0-10）与 valence（情绪正负-5~+5）。选择点的密度与类型跟随曲线：低谷放探索型选择，上升段放小选择积累关系，高潮前放大选择（决策放大张力），高潮后放缓冲型选择（复盘/疗愈）。

节奏编排规则（张弛算法的雏形）

// 每章生成后运行：校验并修正选择点节奏（确定性代码，非LLM）
{
  "chapter_profile": { "type": "tension|breather|revelation|climax",
    "target_density": "high|normal|low" },
  "rules": [
    "gap_ms >= 600字  and gap <= 900字   (小选择间隔)",
    "max_major_per_chapter == 1",
    "major_choice NOT before 60% of chapter",      // 大选择放后段
    "after_major => next 1500字 breather (仅微选择)",  // 张后必弛
    "every 3-4 chapters => 1 breather chapter",
    "climax chapter => 大选择 before peak, 关键选择 at peak"
  ]
}
// 违规则修正：删多余小选择 / 移动大选择位置 / 插入留白段提示LLM补写

05选择节点数据结构与生成提示词

选择节点是结构化数据（随正文同步生成），大选择携带多媒体编排标记。

// choice_node.json —— 单个选择点（由调研4的章节生成流程附带产出）
{
  "id": "C-017",
  "route_id": "route-liuhua", "chapter": 3,
  "position": { "after_paragraph": 12, "at_char": 1860 },
  "level": "major",                          // micro|minor|mid|major|critical
  "psych_type": "value_conflict",           // desire|value|relationship|rule|suspense
  "lead_in": "正文中心理拉扯段落（选项上方的引入文本）",
  "options": [
    { "key": "A", "text": "说出真相",
      "tone_hint": "冲动",
      "consequence": { "scope": "relational",
        "immediate": "老师震惊，关系-2",
        "delayed": "第6章被报复", "delay_ch": 3 },
      "preview_text": "（后果暗示，major以上显示）" },
    { "key": "B", "text": "咽下这句话", ... }
  ],
  "emotional_context": { "tension": 8, "valence": -3 },
  "presentation": {                       // major/critical 的多媒体编排
    "style": "fullscreen",
    "cg": { "scene_desc": "雨夜天台，两人对峙",
      "prompt": "（生图提示词，风格=角色线统一风格）" },
    "bgm": "tense_rain", "sfx": "thunder",
    "timer_sec": 10,                    // 可选限时（Telltale式）
    "warn": "此选择将影响整条故事线" },
  "stats_delta": { "勇气": 1, "关系.老师": -2 },
  "divergence": null                          // critical级别时写入分歧点→调研4世界线
}

大选择的多媒体配合要点

  • CG图：以 scene_desc 生成，风格字段继承角色线统一设定（保证系列图一致性）
  • 音乐/音效：情绪上下文映射到BGM标签库（tense/warm/sad/triumph）
  • 仪式感：全屏暗场+文字浮现+可选倒计时，与前文的小选择形成落差
  • 后果暗示：preview_text 只给模糊暗示（"有人会因此受伤…"），不剧透
  • 落点演出：选择后立即播放一段150-300字的后果文本+CG，兑现"影响深远"的承诺

内心活动选择的写作要点

  • 选项写心理决定而非动作指令（"说，还是不说"优于"点击说话"）
  • lead_in 必须先呈现拉扯（欲望vs顾虑各至少一句）
  • 选项间要等权（无诱导性正确答案），语气差异体现性格侧面
  • 微选择的选项可以是"半句内心话"（增加代入）

提示词一：随正文同步产出选择节点

// 接在调研4的逐章正文生成之后（或合并为一次调用的尾部要求）
基于本章正文，标注选择节点。要求：
1. 识别内心心理活动时刻（欲望冲突/价值权衡/关系临界/规则撕裂/悬念高点）
2. 按 micro|minor|mid|major|critical 分级；major 需 scope≥route 且不可逆
3. 间隔规则：小选择600-900字一个；大选择全章至多1个且位于后1/3；关键选择仅当剧情达到世界级分歧
4. 每个节点：lead_in（正文中的拉扯段落）、2-4个等权选项（心理决定式）、
   每项后果（immediate + delayed + delay_ch）、stats_delta、emotional_context
5. major/critical 额外输出 presentation（cg.scene_desc + 生图prompt + bgm标签 + warn文案）
输出JSON数组：[{ choice_node... }]

提示词二：节奏与情绪审计（对已有正文）

// 对已生成章节做事后体检：找出节奏失衡（也可供人工改稿用）
你是互动叙事的节奏编辑。审读以下章节正文与其选择节点列表：
【正文】{text}　【选择节点】{choices JSON}

输出审计报告（JSON）：
1. 情绪曲线打点：逐场景 tension(0-10) / valence(-5~+5)
2. 节奏诊断：选择过密/过疏的段落位置；连续大选择（过载）；高潮后无缓冲
3. 钩子检查：每个选择后是否有即时反馈；delayed后果是否有登记（防烂尾）
4. 修改建议：删哪个节点/移到哪里/补什么留白（给出位置与理由）

第一阶段 MVP（1周）：方案A

正文生成时同步产出选择节点（提示词一）；五级分类 + 间隔规则写死在提示词与校验代码里；微/小/中选择先用纯文本呈现。

第二阶段 增强（1-2周）：节奏引擎

确定性节奏校验器（P4伪代码落地）：间隔/密度/张弛规则用代码检查，违规自动修正或回退重生成；加入情绪打点与审计提示词（提示词二）。

第三阶段 扩展（1-2周）：大选择多媒体管线

major/critical 的 presentation 落地：CG生成（生图提示词带角色线统一风格字段）、BGM标签库、全屏演出与可选倒计时；关键选择回写分歧点，联动调研4开世界线。

第四阶段 产品化

分岔树回看视图（底特律式flowchart）+ 选择后果追踪面板（delayed后果到期提醒）。TRAE 落地路径：节奏校验器与状态回写用 Python 脚本（确定性），节点生成与审计用 LLM + Skill 封装；全部数据随角色线文件夹存储、可整体迁移。

核心结论

  • 分级看三件事：后果范围（波及谁）、可逆性（能否挽回）、影响时长（多久）——大选择 = 不可逆 + 波及全线，配多媒体；关键选择 = 波及世界线，联动平行宇宙。
  • 频率基准：600-900字一个小选择、每章至多1个大选择、每3-4章一个放缓章——介于网文爽点密度与视觉小说沉浸密度之间，可按题材调节。
  • 节奏是代码不是感觉：情绪打点 + 间隔规则用确定性代码校验，LLM负责生成，规则引擎负责"张弛有度"。
  • 内心活动是最优先的节点类型：欲望冲突/价值权衡/关系临界/规则撕裂/悬念高点五类位置，代入感最强。
  • 五份调研闭环：世界观（1）→角色卡（2）→世界史（3）→角色主线（4）→选择节点（5），状态JSON一脉相承，构成完整互动小说生成管线。
