# Cursor 调研 05：剧情节点控制与设置工具

> 日期：2026-08-26  
> 目标：(a) 区分大/小选择的规则；(b) 节奏与情绪控制——多少字/多久出现抉择点，张弛有度。

---

## 一、结论先行

1. **大/小选择按「结果层次」分，不按选项文案长短分。**  
2. **节奏定量标准可直接借用短剧卡点数据，再按阅读速度换算字数；并下调选择频率（选择比观看更耗精力）。**  
3. **大选择必须有反馈**（动效/配图/音乐）——《黑相集》实测：加涟漪提示后，「选择不重要」抱怨显著下降。

---

## 二、(a) 大选择 vs 小选择

### 2.1 大选择（Crossroad）判定

综合《日落黄昏时》《黑相集》《Episode》与 Emily Short 的 CYOA 结构研究：

| 判据 | 说明 |
|---|---|
| 结果有层次 | 即时 + 延迟（下章）+ 长远（数章后/世界状态） |
| 改持久状态 | 生死、关系、阵营、秘密、规则知晓度 |
| 由既有因果收敛 | 选项候选常由先前选择塑造 |
| 无唯一正确答案 | 选项对比强烈，避免明显最优解 |
| 专属反馈 | 动效 + 多媒体；触发世界状态快照分叉 |

### 2.2 小选择（Flavor）定位

- 探索人物侧面、维持「我在扮演」感。  
- **主线因果不变**；或仅累积属性（勇气+1），后期门槛间接影响。  
- 本质是**节奏工具**，不是叙事爆炸点。

### 2.3 负面验收清单（必须打回）

1. 错误选择：玩家选 A，角色立刻否认。  
2. 误导选择：后果与选项暗示完全相反。  
3. 含糊选择：无法预估后果方向。  
4. 伪分支：两选项收束到同一后续状态。  
5. 二选一严重倾斜（如 85:15）且无设计意图。

正面建议：尽量 ≥3 选项；优势/代价对等；给即时反馈。

### 2.4 可程序化的节点分类器

```
IF 结果写入世界/人物持久状态
AND ≥2 个后果方向显著不同
AND 无明显唯一正确项
→ major（触发多媒体 + 快照分叉）

ELSE IF 仅风味或属性累积
→ minor（纯文本）

IF 两分支后续状态完全相同
→ reject（伪选择）
```

### 2.5 设计结构参考（Emily Short）

- **Track-switching / 确认链**：危险选项多次确认，拉高张力。  
- **Scored choice**：一串小选择累计，决定后期倾向。  
- **Sorting Hat**：早期大选择分轨（慎用，避免后半无互动）。  
- **Endgame Time Cave**：用后期发散兑现前期属性。

工具侧：Twine / ink / Arcweave 做结构草图；Arcweave AI 可审死胡同与节奏。

## 三、(b) 节奏与情绪控制

### 3.1 短剧定量标准（商业验证）

单集万能骨架：

> 黄金 3 秒钩子 → 10 秒内抛清矛盾 → 30 秒内首次反转 → 中段每 15–30 秒情绪点 → 结尾强钩卡死

全剧：

| 位置 | 作用 |
|---|---|
| 1–3 集 | 立人设 + 核心冲突 |
| 约 5–7 集 | 黄金付费/强卡点（过晚转化骤降） |
| 之后每 10–15 集 | 次级卡点；中间留免费爽感区 |
| 中段 | 三集小爆、五集大爆；爽虐交替 |

三种高效卡点形态：身份揭晓前 0.01 秒 / 生死绝境抉择 / 核心秘密将揭未揭。  
共同逻辑：**让用户知道「有事要发生」，不让看到「发生了什么」**。

### 3.2 换算互动小说字数（建议基线）

中文阅读约 300–500 字/分钟；1 分钟短剧信息密度约等于 400–750 字文本。

| 短剧标准 | 互动小说建议 |
|---|---|
| 黄金 3 秒钩 | 开头 **50–150 字**内抛冲突/悬念 |
| 每 15–30 秒情绪点 | 每 **150–300 字**一个情绪点（可无选择） |
| 90 秒一集强钩 | 每 **800–1500 字**一小节，节尾有钩 |
| 轻互动 | **小选择间隔 500–1000 字** |
| 强抉择 | **大选择间隔 3000–8000 字**（约每章 0–1 个） |
| 黄金付费点 | 约第 4–6 章（1.5–3 万字）处设第一个「大选择+解锁」复合点 |
| 张弛 | 连续高压 ≤2 章后必须喘息章 |

**关键下调**：互动小说是「阅读 + 决策」双负载，小选择频率应**低于**短剧刺激频率。宁可用无选择的紧张段落填节奏，也不要全程弹选项。

### 3.3 张弛结构模板

```
密集拉扯区：冲突升级；情绪点密；可穿插小选择
    ↓
大选择（信息差最大点）+ 多媒体反馈 + 状态快照
    ↓
兑现区：立刻给后果（禁止卡点后再长铺垫）
    ↓
喘息区：日常/温情/解谜低速；几乎不弹选择
    ↓
下一轮加压…
```

### 3.4 节奏校验器（可做成工具）

输入章节文本 + 节点标注，输出：

- 距上一小/大选择的字数是否越界  
- 开篇 150 字内是否有钩  
- 连续高压章数  
- 伪分支 / 选项倾斜警告  
- 情绪波形粗标（压/爆交替）

## 五、推荐落地（MVP）

1. 把大/小选择规则写成验收清单 + LLM 打标 prompt。  
2. 在调研 04 章节生成后跑「节奏校验」。  
3. 大选择点：强制 UI 反馈位 + 配图槽 + 世界快照。  
4. 先按上表字数基线跑 1–2 章实测，再按题材调参（怪谈可更疏、甜宠可更密）。

### 风险

- 选择疲劳 → 小选择宁少。  
- 假分支 → 状态 diff 检测。  
- 卡点后欺诈感 → 大选择后立刻兑现。
