## 一、这个文件夹是什么

围绕「互动小说创作工具链」的**五环管线**调研：世界观 → 人物 → 世界脉络 → 角色小说 → 剧情节点。每环都给出了：现成工具盘点、关键机制设计、推荐落地方案、主要风险。

```
01 世界观设定          02 人物设定           03 世界脉络模拟
自然语言 → 基本盘冻结 → 角色卡(V2/V3)+关系网 → 规则引擎+编年史+快照
       │                      │                       │
       └──────────┬───────────┴───────────────────────┘
                  ▼
         04 角色小说推进（共享世界状态 + 多视角渲染 + 摘要链/伏笔表）
                  ▼
         05 剧情节点控制（大/小选择分级 + 节奏校验 + 快照分叉）
```

## 三、隔离约定（与 ai-storyline 的关系）

1. **代码/文档互不改动**：PlanB 的一切产物在独立新目录 `../planb/`（**独立 git 仓库**）中进行，不修改 `ai-storyline/`。
2. **独立路线**：PlanB 不承担「给 ai-storyline 打补丁」的任务；两条路线各自演进，必要时再比较取舍。
3. **git 彻底分离**：`../planb/` 自建 git 仓库（外层 .gitignore 已排除），与 `ai-storyline/` 无共享提交历史。
4. 调研中引用的技术栈（Godot、ink、ComfyUI 配图、chara_card_v3 等）属 PlanB 路线假设，与 ai-storyline 的 Web+Python 栈无关。

## 六、关键数字备忘

- 小选择间隔 **500–1000 字**；大选择间隔 **3000–8000 字**（每章 0–1 个）
- 开篇 **50–150 字**内必须抛出钩子；每 **150–300 字**一个情绪点
- 微观智能体模拟 **≤50 agents**、仅关键片段；宏观编年史以「年/时代」为 tick
- 连续高压 **≤2 章**后必须喘息章；大选择后**立刻兑现**后果
