# 互动小说项目调研总览

> 五份调研的串联合论：整体管线怎么走、每环用什么、先做什么。
> 日期：2026-08-26

---

## 一、整体管线（五环串联）

```
01 世界观设定          02 人物设定           03 世界脉络模拟
自然语言 → 基本盘字段  ─→ 世界观驱动生成     ─→ 规则引擎 + 编年史
(JSON Schema 冻结)      角色卡(V3规范)        推演 N 年大事年表
       │                       │                      │
       └───────────┬───────────┴──────────────────────┘
                   ▼
          04 角色小说推进
          选定角色 → 个人主线大纲 → 逐章生成
          (共享世界状态 + 视角渲染 + 摘要链/伏笔表)
                   │
                   ▼
          05 剧情节点控制
          节点打标(大/小选择) + 节奏校验(字数/卡点)
          大选择 → 快照分叉 + 配图(ComfyUI) + 界面反馈
```

## 二、每环核心结论一句话

| # | 模块 | 结论 | 关键参照 |
|---|---|---|---|
| 01 | 世界观设定 | 没有现成品，但「Schema 驱动对话 + Lorebook 记忆 + 矛盾检测」自建管线完全可行 | World Anvil 模板、NovelAI/SillyTavern Lorebook、Mythos |
| 02 | 人物设定 | **五环中现成标准最多的一环**：直接采用 chara_card_v3 开放规范 | SillyTavern 角色卡生态、Talefy/Story321 |
| 03 | 世界脉络 | 分层模拟：宏观编年史（规则引擎+LLM）为主，微观智能体（≤50 个）按需 | Smallville/AI Town、DeepMind Concordia、Narra |
| 04 | 角色小说 | 单一共享世界状态 + 多视角渲染；骨架(ink/大纲)确定性 + 血肉(LLM)生成 | MidReal、彩云小梦（平行世界回溯）、ink |
| 05 | 节点控制 | 大/小选择按「结果层次」区分；节奏直接套用短剧卡点数据换算字数 | 《日落黄昏时》《黑相集》《Episode》、短剧卡点研究 |

## 三、贯穿五环的公共基础设施（先建这些最划算）

1. **统一数据格式**：世界观 JSON Schema + chara_card_v3 角色卡 + 世界状态 JSON——三环共享，后续环节全部读写这套数据；
2. **Lorebook 注入器**：关键词命中 → 设定条目注入上下文，解决一切"长篇失忆"问题（01/02/04 复用）；
3. **一致性校验器**：规则自检（每段输出是否违反编号世界规则）+ 矛盾检测（01/03/04 复用）;
4. **摘要链 + 伏笔表**：长篇连贯性的工程解法（03/04 复用）；
5. **多档模型路由**：便宜模型做摘要/补全，大模型做规则推演/正文（控成本，全环复用）。

## 四、建议实施顺序

1. **先做 01 + 02**（世界观→人物）：数据格式是地基，且角色卡可直接用 SillyTavern/Chara Snap 人工微调验证，无需先写编辑器；
2. **再做 04 的简化版**（单角色主线逐章生成 + 摘要链）：这是用户体验的核心，先用固定大纲跑通"世界观+角色卡→章节正文"；
3. **05 紧随其后**（节点打标 + 节奏校验器）：让 04 的输出从"小说"变成"互动小说"；
4. **03 最后做且只做宏观层**：编年史引擎（规则 YAML + LLM 年表）独立性强，微观智能体模拟等确有需求再上；
5. 规则怪谈类项目注意：**玩家/角色知识状态表**（谁知道哪条规则）要在 01 的 Schema 里预留字段。

## 五、最值得先细读的三个开源仓库

| 仓库 | 学什么 |
|---|---|
| `gqy20/narra`（MIT） | 数据驱动叙事模拟：YAML 声明世界规则/剧情线 + Go 权威规则内核 + 批量仿真；且是 Godot 客户端，与你技术栈吻合 |
| `a16z-infra/ai-town`（MIT） | 智能体 tick 循环、记忆流检索、世界状态维护的工程实现 |
| `SillyTavern/SillyTavern` | 角色卡/世界书/群聊的完整产品化实现，02 与 04 的直接底座 |

## 六、主要风险汇总

1. **长篇一致性**：任何单一机制都不够，必须 Lorebook + 摘要链 + 伏笔表 + 状态表组合；
2. **成本失控**：微观智能体模拟是成本黑洞，严格限制在关键片段、≤50 智能体；
3. **选择疲劳**：小选择频率宁低勿高，用"无选择的紧张段落"填节奏；
4. **AI 人设模板化**：人物生成 prompt 强制要求缺陷/秘密/矛盾点 + 生成后压力 QA；
5. **字段贪多**：世界观与人物 schema 只收"能制造剧情张力"的字段，装饰性设定不进核心层。
