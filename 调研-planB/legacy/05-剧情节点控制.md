# 调研 05：剧情节点控制与设置工具

> 目标：在已有剧情中找出供用户选择的节点（常涉及心理活动）。
> (a) 区分大/小选择的规则；(b) 节奏与情绪控制——多少字/多久出现一个抉择点，张弛有度。

---

## 一、结论先行

1. **大/小选择的区分在游戏行业已有成熟方法论**：以《日落黄昏时》的「关键抉择（Crossroad）」体系、《黑相集》创意总监的三规则、《Episode》的选择设计准则为代表——核心判据是**结果的层次**（即时/延迟/长远）而非选项文本本身。
2. **节奏控制的最硬数据来自短剧行业**：付费卡点位置、单集节奏公式（黄金 3 秒、每 15-20 秒一个情绪点、结尾强钩）都是经过大规模商业验证的定量标准，可直接换算成互动小说的"多少字一个抉择点"。
3. **大选择必须有界面/媒体反馈**（《黑相集》实测：加了"涟漪效果"提示后，玩家"选择不重要"的抱怨消失）——这正好衔接你"大选择配合图片/多媒体"的设想。

---

## 二、(a) 大选择 vs 小选择的区分规则

### 2.1 大选择（关键抉择 / Crossroad）的判定标准

《日落黄昏时》（As Dusk Falls）设计准则：**每个场景至少一处体现玩家自主权、有实质意义和影响的选项**。大选择的特征：

| 判据 | 说明 |
|---|---|
| **结果有层次** | 产生即时结果 + 延迟结果（下一场景/下一章）+ 长远结果（数章甚至 14 年后的人物状态）三层连锁反应 |
| **改变人物状态** | 生死、关系破裂/修复、阵营转换、秘密曝光——写入人物与世界的持久状态 |
| **被既有事态塑造** | 大选择本身由玩家此前选择收敛而来（如"让谁离开旅馆"的候选由先前剧情决定），形成因果网 |
| **可用故事矩阵追踪** | 用 2×2 故事矩阵可视化：早期二选一如何在后期场景交汇——大选择是矩阵的交叉点 |
| **无"正确"答案** | 《黑相集》规则：选项目的必须对比强烈，且避免明显正确答案，让玩家纠结 |
| **有专属反馈** | 触发界面提示（蝴蝶/乌鸦/涟漪动效），多媒体资源（配图/音乐）只在大选择点投入 |

### 2.2 小选择（风味选择 / Flavor Choice）的定位

- 探索人物不同侧面、让时刻更有风味，**不改变主线因果**（《日落黄昏时》明确承认并非每个选项都有惊天动地的意义）；
- 《黑相集》：低重要性选择的价值是**避免选择疲劳** + 让玩家持续感觉在"扮演"角色——**小选择是节奏工具，不是叙事工具**；
- 数值化产品（ChoiceScript / Episode 类）：小选择累积成**属性参数**（勇气+1、好感-1），属性门槛在后期解锁/锁死分支——小选择通过参数间接影响大走向。

### 2.3 选择设计的负面规则（《Episode》创意经理总结，直接可用作验收清单）

必须避免的三种选项：
1. **错误选择**：玩家选 A 后角色立即否认/反悔（永远不要让角色否认玩家的选择）；
2. **误导性选择**：实际剧情走向与选项暗示的方式完全不同；
3. **含糊选择**：玩家无法预估选项的后果方向。

正面规则：每个选择要有明确的意义、目标和结果；给即时反馈；尽量给 **3 个以上选项**（二选一 YES/NO 数据上往往严重倾斜，如 85%:15% 即设计失败）；选项间优势/损失要对等。

### 2.4 落地为「节点分类器」的规则（可程序化）

在生成管线中，可用如下规则让 LLM 给候选节点打标：
- **大选择**：选择结果会写入世界/人物持久状态（状态表有字段变化）∧ 存在 ≥2 个可行且后果方向不同的分支 ∧ 无明显的"正确"项 → 标记 `major`，触发多媒体管线与快照分叉；
- **小选择**：只影响当章叙事风味或累积属性参数 → 标记 `minor`，纯文本；
- **伪选择检测**：若两个选项收束到完全相同的后续状态，打回重写（避免"假分支"）。

## 三、(b) 节奏与情绪控制

### 3.1 短剧行业的定量标准（商业验证过的数据）

**单集节奏公式**（拆解 100+ 部亿级播放爆款得出）：
> 黄金 3 秒钩子 + 10 秒抛冲突 + 30 秒首次反转 + 中段每 15-20 秒一个小冲突/爽点 + 结尾强钩

- 开场 3 秒抓不住人，60%+ 用户直接划走；
- 情绪曲线：压→爆→压→爆，爽点后微虐、虐点后立刻爽，**避免全程高能（疲劳）也避免一平到底**；
- 镜头/台词原则：每句 ≤10 字、1-2 秒/镜、硬切——对应到小说即**短句、快节奏段落**。

**全剧节奏（付费卡点数据）**：
| 位置 | 作用 |
|---|---|
| 第 1-3 集 | 建立人设与核心冲突（核心冲突要在第 1 集前 30 秒抛出），观众决定追不追 |
| **第 5-7 集：黄金付费点** | 第一次情绪高峰后、关键反转前 0.01 秒卡点，付费转化 15-18%；拖到第 8 集后降到 5% 以下 |
| 之后每 10-15 集一个次级卡点 | 卡点间留"免费爽感区"，让用户觉得值 |
| 中段（6-30 集） | 三集一小爆、五集一大爆，爽点虐点交替 |

**卡点内容的三种最有效形态**（直接决定"在什么剧情节点给用户做选择"）：
1. **身份揭晓前 0.01 秒**（玉佩掏出、反派变色——黑屏）；
2. **生死/绝境抉择时**（"跳下去，或者嫁给我"）；
3. **核心秘密即将揭开时**（翻开日记看到名字，表情震惊）。

共同逻辑：**让用户知道"有东西要发生"，但不让看到"发生了什么"——信息差就是继续的动力**。且卡点之后必须立刻兑现（付费后第一集还在铺垫 = 欺诈感，流失）。

### 3.2 换算成互动小说的字数节奏

按中文阅读速度 300-500 字/分钟换算（1 分钟短剧 ≈ 400-750 字文本信息密度）：

| 短剧标准 | 互动小说换算建议 |
|---|---|
| 黄金 3 秒开场钩 | **开头 50-150 字内**必须抛出核心冲突或强悬念 |
| 每 15-20 秒一个小冲突 | **每 150-300 字**一个情绪点（小反转/新信息/小爽点） |
| 90 秒一集 + 结尾强钩 | **每 800-1500 字一个小节**，节尾必须有钩子 |
| 3 秒级选择疲劳管理 | **小选择间隔 500-1000 字**（约 1-3 分钟阅读一次轻互动） |
| 每集一个强钩/卡点 | **大选择间隔 3000-8000 字**（每章 1 个左右，对应调研 04 的章节结构） |
| 黄金付费点第 5-7 集 | 若为付费产品：第 4-6 章（约 1.5-3 万字处）设第一个"大选择+付费/解锁"复合卡点 |
| 爽点虐点交替 | 情绪波形管理：连续高压 ≤2 章后必须给喘息章（日常/温情/解谜低速段） |

> 注意：互动小说与短剧的关键差异是**选择本身消耗用户精力**。短剧是被动接收高密度刺激，互动小说是"阅读 + 决策"双重负载——所以小选择频率应低于短剧的刺激频率，**宁可用"小冲突"（无选择的紧张段落）填节奏，也不要全程弹选项**（《黑相集》的疲劳管理结论）。

### 3.3 张弛结构设计

```
密集区（拉扯）：冲突升级段，小冲突每 150-300 字一个，
   小选择 500-800 字一次，以"大选择"收尾 → 情绪峰值
   ↓
兑现区：大选择的即时后果立刻呈现（欠的反转马上还）
   ↓
放缓区（释放）：1-2 个低速章节——展示后果涟漪、人物日常、
   世界细节、伏笔回收；此段几乎不给选择，让用户"看后续剧情"
   ↓
蓄势区：新线索/新威胁渗入，情绪缓升 → 进入下一个密集区
```

- 放缓区的合法内容：大选择的长远后果显现（14 年后式回响）、NPC 视角插曲、世界观氛围段落——**放缓不是水，是让用户欣赏自己选择的后果**；
- 付费/解锁卡点只放密集区末尾的大选择处（临界爆发点），永远不放放缓区。

### 3.4 大选择的多媒体配合（对接生图管线）

- 触发规则：`major` 节点 → 调用图像生成（你的 ComfyUI CPU 版或 ImageGen）产出场景图/角色表情差分；V3 角色卡的 `assets`（emotion 表情差分、background 背景）正好承载；
- 界面反馈必须显式：分支提示动效/标记（涟漪、蝴蝶）——《黑相集》实测这是"选择感"的来源，没有提示用户会觉得选了白选；
- CPU 生图慢 → 大选择节点在剧情生成时**预生成缓存**，不要在用户点到时现算。

## 四、推荐落地方案

1. **节点标注器**：章节大纲生成时（调研 04 的接口），LLM 按 2.4 规则给每个候选节点打 `major`/`minor` 标，并给出该节点的"卡点形态"（身份揭晓/绝境抉择/秘密揭开/其他）；
2. **节奏校验器**：成稿后按 3.2 的字数表自动检测——连续多少字无情绪点、大选择间距是否超标、高压章是否连超 2 章——输出节奏报告供修改；
3. **验收清单**：每个选择过一遍 2.3 的负面规则（错误/误导/含糊/二选一倾斜）；
4. 大选择节点联动：状态快照分叉（调研 04）+ 配图预生成 + 界面反馈标记。

**主要风险：**
- LLM 对"0.01 秒卡点"的把握不稳定 → 卡点形态模板化（三类形态写进 prompt 示例）；
- 字数节奏机械执行会伤害好故事 → 节奏报告作为建议而非硬门禁，人工拍板。
